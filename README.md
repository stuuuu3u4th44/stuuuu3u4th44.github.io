# Lovecut — парикмахерская в Иркутске

Сайт парикмахерской **Lovecut** — Иркутск, Литвинова 18.

- Тёмная черничная цветовая схема с ванильными акцентами

- Пиксельная анимация флага и фотографий

- Модальное окно с картой

## Технологии
